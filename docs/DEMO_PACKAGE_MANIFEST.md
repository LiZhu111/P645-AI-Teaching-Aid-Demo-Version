# Demo package contents

This package preserves the project source code, frontend implementation, scripts, tests, planning documents, and engineering documentation. Planning and engineering documents are retained without edits.

The runnable app uses fictional course, lesson, criterion, assessment, learner, and feedback examples in `data/`. Original customer source files in `docs/brief/` and the production course/assessment records are excluded. Browser evidence screenshots are excluded because they display original course text. The repository Git history is not included.

Planning and engineering documents may still refer to the project partner, course identifiers, and findings derived from the original dataset. Review those references before making this package public.
